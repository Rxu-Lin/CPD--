# 3D 模型导入与优化

在「3D 模型预览」导入 OBJ、FBX 或 GLB 后，选中模型，在右侧「模型优化」中操作。

- **仅压缩（默认）**：保留三角面，通过 Draco 压缩几何数据，清理当前纯色预览不使用的贴图和属性。
- **轻度减面 / 中度减面**：分别以保留 75% / 50% 三角面为目标；细节误差限制可能使实际面数高于目标。
- 优化完成后可以切换原始 / 优化后画面，并查看文件大小、实际三角面数和本次解析耗时。
- 选择「应用优化模型」后保留模型的位置、角度、缩放和颜色；当前会话可以 Ctrl+Z 撤销。也可保留原模型或单独下载 GLB。
- 优化副本是当前姿态的纯色静态模型，不保留动画、骨骼编辑或原始贴图；原始文件仍在本地，未被覆盖。几何压缩包含有限精度量化，应用前请检查细节。
- 极小或已压缩模型可能不会更小，面板会按实际结果提示。解析耗时包含解码器初始化，不代表稳定的速度提升。

## 保存和迁移

新导入的模型作为二进制文件保存在 `.project-cache/00000000-0000-4000-8000-000000000000/models/`，按内容哈希共用资源；浏览器场景仅保存资源路径及编辑参数。旧 Base64 场景在恢复时尝试迁移，迁移失败仍可读取原数据。

项目 ZIP 包包含所引用的模型文件，支持 GLB。换设备前请保存或导出项目 ZIP；不要手工删除正在使用的 `.project-cache` 资源。模型优化和解码均在本机运行，不需要生图 API。
