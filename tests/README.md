# 手绘画板回归测试

运行 `npm run test:sketch`，验证图层排序、可编辑数据、工作流连线及失败保护。

可选的完整检查：

- `SKETCH_CANVAS_MODULE`：已安装的 `@napi-rs/canvas` 模块路径，用于真实像素合成测试。也可以直接在测试环境安装该模块。无需将其加入网站运行依赖。
- `SKETCH_TEST_API`：运行中的本地网站地址，例如 `http://localhost:5174`。启用后会测试 ZIP 打包、重新导入和资源读取，只接受本机地址。

两个可选项都可用时共运行 9 项测试。缺少环境时相关测试会明确跳过，不会访问外部生成 API。ZIP 测试使用合成图片与 `fixtures/sketch-pyramid.obj`，在系统临时目录生成检查用项目包，不读取用户画板或密钥。

手动验收：

1. 从左侧「手绘画板」进入，绘制线条，添加模型，确认角度。
2. 将绘画层上下移动，确认模型前后遮挡；用橡皮检查下层仍保留。
3. 检查锁定、隐藏、透明度、复制、撤销和重做。
4. 在 9:16 比例下生成，检查参考图、提示词、生成框连线及间距。
5. 点击手绘参考图重新打开，检查笔画、模型与构图。
6. 保存 ZIP，重新导入，在模型图层中再次打开 OBJ/FBX 场景继续编辑。

注意：这里的绘画层是二维构图，不是模型表面的贴图。改变模型角度后，笔画不会自动贴合新视角。
